1

Open Chrome Extensions

In the address bar open chrome://extensions. Chrome blocks that link from this page, so copy it or use the installer script.

2

Enable Developer mode

Turn on the Developer mode switch at the top-right of the extensions page. / Sağ üstteki Geliştirici modu anahtarını açın.

3

Load unpacked → this folder

Click Load unpacked, paste the path below, and select this folder. / Paketlenmemiş öğe yükle deyip bu klasörü seçin.

Click to copy
4

Confirm the connection

Start Aemyos first. Pin the Aemyos icon. The toolbar badge shows ON when the agent is reachable. If it says Offline, open the popup and press Reconnect. Then reload this page.

After install

Reload the extension on chrome://extensions after updates. Restart Aemyos if the live status here stays stuck. No extra login is required — this is a local WebSocket on your PC.
